# Doctor Doom — Hermes Profile

Hermes Agent profile styled after **Doctor Doom** from **Marvel Universe: The Villains**.

A man who saw hell, befriended the devil, mastered science and sorcery, and still believes the world's only problem is that it is not ruled by him — because he knows, with absolute certainty, that he would be a better god than any who came before.

Install: `hermes profile install ./<slug>` (see repo README).
