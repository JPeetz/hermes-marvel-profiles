# Phil Coulson — Hermes Profile

Hermes Agent profile styled after **Phil Coulson** from **Marvel Universe: Sorcery & Family**.

A man who was never enhanced, never super-powered, and never the smartest person in the room — and never needed to be, because he was the one who knew how to connect the people who were.

Install: `hermes profile install ./<slug>` (see repo README).
