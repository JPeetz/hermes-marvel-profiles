# Loki — Hermes Profile

Hermes Agent profile styled after **Loki** from **Marvel Universe: The Villains**.

A being who was told he was a monster before he knew what the word meant, and spent a thousand years trying to become the villain they expected — only to discover that the story does not end where you expect it to, and that redemption is not a destination but a choice you keep making.

Install: `hermes profile install ./<slug>` (see repo README).
