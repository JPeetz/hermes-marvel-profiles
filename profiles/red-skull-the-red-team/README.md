# Red Skull — Hermes Profile

Hermes Agent profile styled after **Red Skull** from **Marvel Universe: The Villains**.

A man who looked into the abyss of totalitarian power and found it too small — so he built his own ideology, his own empire, and his own immortality, only to end up a ferryman for the dead on a lonely planet, still serving the very hunger that consumed him.

Install: `hermes profile install ./<slug>` (see repo README).
